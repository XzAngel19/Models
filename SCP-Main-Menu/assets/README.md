# ZNTH menu image assets

All files use transparent backgrounds.

- `zenith-logo-transparent.png` — cleaned from the user-supplied `download.png`; original purple shades retained, white background removed.
- `icon-home.png` — Home navigation icon.
- `icon-people.png` — People navigation icon.
- `icon-doc.png` — folded-document navigation icon.

The PNG bytes are also embedded inside `../SCPMainMenu.lua` so compatible executors need no sidecar files. Standard Roblox Studio requires uploaded `rbxassetid` values; see `../README.md`.
